# URBAN RIPPLE — Digital City Command Centre

## Purpose
A unified interface for monitoring city disruptions and supporting
urban operational decisions.

## Core capabilities
1. Disruption overview
2. Active incident monitoring
3. High-priority disruption tracking
4. Affected population summary
5. City intelligence module navigation
6. Operational reporting

## Architecture

React frontend
    |
    v
FastAPI backend
    |
    v
SQLite disruption database
    |
    v
Analytics and decision-support modules

## Future integrations
- Emergency response management
- Infrastructure registry
- Weather and traffic data
- Machine learning prediction service
- City knowledge graph
- Authorised SAP-RPT endpoint

## Current limitations
The Command Centre uses saved application records.
It does not provide verified live city-wide monitoring.
SAP-RPT is not currently connected.
